# 二期接口设计 — RAG 知识库与综合推理

| 项目 | 内容 |
| ---- | ---- |
| **文档编号** | API-PHASE2-2026-001 |
| **文档版本** | V1.0 |
| **依据文档** | 《二期-需求文档》V1.0；《二期-系统设计》V1.0；《二期-数据库设计》V1.0；API-LLD-2026-001 |

## 1. 约定

### 1.1 错误码（沿用并扩展）

| code | 含义 |
| ---- | ---- |
| 0 | 成功 |
| 1001 | 未登录 |
| 1003 | 无权限 |
| 2001 | 参数非法 |
| 4004 | 资源不存在 |
| 5001 | AI 网关异常 |
| 5002 | AI 超时 |
| **5201** | 知识库未就绪 / 发布冲突 |
| **5202** | 综合推理已关停（可降级，一般不抛给前端而走简化模式） |
| **5203** | Agent Run 不可打断或不存在 |
| **5204** | 向量/解析任务失败 |

### 1.2 SSE 通用

- `Content-Type: text/event-stream`
- `Cache-Control: no-cache`
- `X-Accel-Buffering: no`
- 事件块：`id` / `event` / `data(JSON)`
- 终端事件：`suggest_done` | `agent_done` | `error`

### 1.3 权限角色

| 接口组 | advisor | supervisor | admin |
| ------ | ------- | ---------- | ----- |
| 侧边栏回复/Agent | ✓ | ✓ | ✓ |
| 知识库管理 | ✗ | ✓（可选） | ✓ |
| 功能开关 | ✗ | ✗ | ✓ |
| 盲区/反馈看板 | ✗ | ✓ | ✓ |

## 2. 侧边栏 — 回复建议（扩展一期）

### 2.1 生成建议（SSE）— 入口保持不变

**`POST /api/v1/reply/suggestions/stream`**

权限：登录顾问 + 客户可访问。

**Request Body（同分期兼容，增量可选字段）：**

```json
{
  "conversationId": 2,
  "customerId": 3,
  "currentMessage": {
    "type": "text",
    "text": "孩子初二数学六七十分，想暑假主攻数学顺便接触物理，有什么方案和价位？"
  },
  "scenarioHint": null,
  "preferMode": null
}
```

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| preferMode | string | 否 | `legacy`/`rag`/`agent`；仅调试。生产由服务端 Intent 决定 |

**服务端分流：**

1. 若 `agent_reasoning_enabled=false` → 仅 `legacy` 或 `rag`（视 `kb_rag_enabled`）。
2. 客观事实 → `rag`。
3. 组合型 → `agent`。
4. 其他 → `legacy`（一期 InferReply）。

#### 2.1.1 模式 A：`legacy`（一期行为）

事件同现网：

| event | data 示例 |
| ----- | --------- |
| `suggest_chunk` | `{"candidateId":1,"delta":"..."}` |
| `suggest_done` | `{"scenarioTags":[],"profileVersion":3,"latencyMs":820,"eventId":99,"mode":"legacy"}` |

#### 2.1.2 模式 B：`rag`

| event | data | 说明 |
| ----- | ---- | ---- |
| `rag_status` | `{"status":"searching"}` | 可选 |
| `suggest_chunk` | `{"candidateId":1,"delta":"..."}` | 据实文本流 |
| `suggest_done` | 见下 | |

`suggest_done`（RAG）：

```json
{
  "scenarioTags": ["price_inquiry"],
  "profileVersion": 3,
  "latencyMs": 1100,
  "eventId": 100,
  "mode": "rag",
  "fallback": false,
  "citations": [
    {
      "type": "kb_chunk",
      "refId": "88",
      "label": "根据集团概况（2026版）",
      "updatedAt": "2026-08-01T00:00:00Z",
      "excerpt": "擎天学智成立于…"
    }
  ],
  "uncertaintyNotes": []
}
```

兜底时：

```json
{
  "eventId": 101,
  "mode": "rag",
  "fallback": true,
  "citations": [],
  "uncertaintyNotes": [],
  "latencyMs": 400,
  "scenarioTags": [],
  "profileVersion": 3
}
```

兜底正文示例（经 chunk 推送）：  
`这个问题我暂时帮不上忙，您的专属课程顾问小王对这方面很了解，随时可以问她~`

#### 2.1.3 模式 C：`agent`

| event | data | 说明 |
| ----- | ---- | ---- |
| `agent_start` | `{"runId":501,"maxSteps":3}` | 任务开始 |
| `agent_step` | 见下 | 每步一条 |
| `suggest_chunk` | `{"candidateId":1,"delta":"..."}` | 最终建议流式（可在 synthesize 阶段） |
| `agent_done` / `suggest_done` | 见下 | 二者可合并为只发 `suggest_done`（推荐减少前端分支） |

**推荐：终端统一 `suggest_done`，步骤用 `agent_step`。**

`agent_step`：

```json
{
  "runId": 501,
  "stepIndex": 1,
  "phase": "tool_call",
  "capability": "profile_get",
  "title": "正在了解学生情况…",
  "status": "ok",
  "summary": "初二；数学薄弱标签；预算约1万内",
  "sourceRefs": [
    {
      "type": "profile_tag",
      "refId": "12",
      "label": "数学薄弱",
      "updatedAt": "2026-08-01T00:00:00Z"
    }
  ]
}
```

`suggest_done`（Agent）：

```json
{
  "scenarioTags": ["course_recommend", "price_inquiry"],
  "profileVersion": 3,
  "latencyMs": 4200,
  "eventId": 200,
  "mode": "agent",
  "runId": 501,
  "fallback": false,
  "status": "success",
  "citations": [
    {
      "type": "profile_tag",
      "refId": "12",
      "label": "学生数学水平：根据画像标签",
      "updatedAt": "2026-08-01T00:00:00Z"
    },
    {
      "type": "kb_chunk",
      "refId": "90",
      "label": "推荐课程：根据 2026 暑期开班计划",
      "updatedAt": "2026-07-01T00:00:00Z"
    }

  "uncertaintyNotes": [
    "该建议基于部分信息推断，建议核实孩子近期数学是否已提高后再发送"
```

`status`：`success` | `insufficient` | `failed` | `interrupted`。

### 2.2 采纳 / 拒绝（一期兼容）

**`POST /api/v1/reply/suggestions/{eventId}/feedback`**

Body 不变：

```json
{
  "candidateId": 1,
  "action": "adopt_and_send_manually",
  "finalText": "顾问可能编辑后的文本"
}
```

说明：`adopt_and_send_manually` **不**触发企微代发；仅回写采纳。  
`mode=agent/rag` 时同样走本接口，便于统一采纳率统计。

---

### 2.3 打断综合推理

**`POST /api/v1/reply/agent/runs/{runId}/interrupt`**

权限：该 run 所属顾问本人（或 admin）。

**Request：**

```json
{
  "reason": "direction_wrong",
  "hint": "孩子数学最近进步很大，按提高班匹配"
}
```

| 字段 | 必填 | 说明 |
| ---- | ---- | ---- |
| reason | 否 | `direction_wrong` / `user_cancel` / `other` |
| hint | 否 | V1 可只停止；V1.1 可用 hint 再综合 |

**Response `data`：**

```json
{
  "runId": 501,
  "status": "interrupted"
}
```

行为：设置 Redis 取消标记；Runtime 在下一步前停止 tool；若已有证据则尽量输出 `insufficient/interrupted` 建议。

---

### 2.4 推理结果反馈（「有问题」）

**`POST /api/v1/reply/agent/runs/{runId}/feedback`**

```json
{
  "isNegative": true,
  "comment": "推荐了基础班，但孩子已提高",
  "issueTags": ["stale_profile", "wrong_course_level"]
}
```

**Response：**

```json
{
  "feedbackId": 9,
  "runId": 501
}
```

### 3.2 上传文档

**`POST /api/v1/admin/knowledge/documents`**

`multipart/form-data`：

| 字段 | 说明 |
| ---- | ---- |
| file | 文件（md/pdf/docx/txt） |
| category | 四类之一 |
| title | 标题 |
| docKey | 逻辑键；不传则服务端生成 |
| effectiveFrom / effectiveTo | 可选 ISO8601 |

**Response：**

```json
{
  "id": 15,
  "status": 1,
  "message": "已受理，解析中"
}
```

异步：解析 → 切分 → embedding → `status=2` 待审核。

### 3.3 文档详情

**`GET /api/v1/admin/knowledge/documents/{documentId}`**

## 7. AI 远端契约（AI Gateway 扩展）

基址：`AI_REMOTE_BASE_URL`（同分期）。业务经 `ai_gateway` 调用，不对外暴露。

### 7.1 RAG 回答

**`POST /v1/rag/answer`**

```json
{
  "question": "你们做了多少年了",
  "advisorName": "小王",
  "chunks": [{ "chunkId": 88, "content": "...", "score": 0.86 }],
  "fallbackTemplate": "这个问题我暂时帮不上忙，您的专属课程顾问{advisorName}对这方面很了解，随时可以问她~"
}
```

**Response：**

```json
{
  "text": "...",
  "fallback": false,
  "citations": [{ "chunkId": 88 }],
  "modelVersion": "rag-v1"
}
```

若 `chunks` 为空或业务已判定低分，可本地直接套模板，不调用远端。

### 7.2 Agent 规划

**`POST /v1/agent/plan`**

```json
{
  "question": "...",
  "capabilities": [
    {
      "name": "profile_get",
      "description": "查询客户画像与学情标签"
    }
  ],
  "context": { "customerId": 3 }
}
```

**Response：**

```json
{
  "steps": [
    { "capability": "profile_get", "args": { "customerId": 3 }, "title": "正在了解学生情况…" },
    { "capability": "course_plan_search", "args": { "query": "初二 数学 物理 暑假" }, "title": "正在匹配课程…" },
    { "capability": "kb_search", "args": { "query": "暑假班价格 优惠", "category": "faq" }, "title": "正在核对价格和优惠…" }
  ],
  "modelVersion": "agent-plan-v1"
}
```

约束：返回 capability 必须 ⊆ 注册白名单；步数 ≤ `max_steps`。

### 7.3 Agent 综合

**`POST /v1/agent/synthesize`**（可流式 SSE）

```json
{
  "question": "...",
  "evidence": [
    { "capability": "profile_get", "data": {}, "sourceRefs": [] }
  ],
  "advisorName": "王芳"
}
```

流式事件对齐业务：`suggest_chunk` + 最终 JSON 含 `uncertaintyNotes` / `citations`。

### 7.4 意图分类（可选）

**`POST /v1/reply/intent`**

```json
{ "text": "...", "hasProfile": true }
```

```json
{ "intent": "agent_complex|kb_fact|legacy_chat", "confidence": 0.81 }
```

可用规则引擎替代，降低时延。

## 8. 核心时序（接口视角）

### 8.1 Agent 成功路径

```
Sidebar → POST /reply/suggestions/stream
App → Redis GET feature_flag
App → (optional) POST AI /v1/reply/intent
App → SSE agent_start
App → POST AI /v1/agent/plan
App → capability profile_get / course_plan / kb_search   (SSE agent_step × N)
App → POST AI /v1/agent/synthesize (SSE suggest_chunk)
App → INSERT agent_run/steps + suggestion_event
App → SSE suggest_done
Sidebar → 顾问编辑 → POST .../feedback (adopt_and_send_manually)
Advisor → 企微原生窗口手动发送
```

### 8.2 关停路径

```
Admin → PUT /admin/feature-flags/agent_reasoning_enabled {enabled:false}
App → DB + Redis
Sidebar → POST /reply/suggestions/stream
App → mode != agent （legacy 或 rag）
```

## 9. 前端事件订阅清单（侧边栏）

| event | 处理 |
| ----- | ---- |
| `agent_start` | 展示「综合分析中」，记录 runId |
| `agent_step` | 追加步骤流水 |
| `suggest_chunk` | 追加建议正文 |
| `suggest_done` | 展示引用、不确定提示、反馈按钮；保存 eventId |
| `error` | 错误提示；可重试 |

打断：用户点击 → `POST .../interrupt`；监听后续 `suggest_done.status=interrupted`。

## 10. 测试用例锚点（接口级）

| 编号 | 场景 | 期望 |
| ---- | ---- | ---- |
| T1 | 问「做了多少年」且库中有概况 | `mode=rag`, `fallback=false`, citations 非空 |
| T2 | 问主观「老师好不好」 | 不进 RAG 编造；legacy 或明确拒答策略（产品定） |
| T3 | 王芳组合问题 | `mode=agent`，steps 含 profile + course + kb，≤5s |
| T4 | 关停后再问组合问题 | `mode≠agent` |
| T5 | 发布 course_plan 未勾选 confirm | 2001 |
| T6 | 低分检索 | `fallback=true`，正文含顾问名，写 blind_spot |
| T7 | interrupt | run status=interrupted，不再调后续 tool |
